# Badmak · Archivo Histórico

Aplicación Android del archivo histórico 2037–2145.

## APK
Cada cambio en `main` ejecuta GitHub Actions y genera un artefacto llamado **Badmak-APK** con el archivo `Badmak.apk`.

La aplicación funciona sin conexión: el archivo histórico está empaquetado dentro de la propia APK.
